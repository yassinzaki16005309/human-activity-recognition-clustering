# human-activity-recognition-clustering
# Human Activity Recognition using Unsupervised Machine Learning

## Overview

This project applies unsupervised machine learning techniques to identify patterns in human activity data. The workflow includes data preprocessing, dimensionality reduction using Principal Component Analysis (PCA), and comparison of multiple clustering algorithms to evaluate their ability to group similar activities.

## Objectives

- Preprocess and clean the dataset
- Reduce dimensionality using PCA
- Determine the optimal number of clusters
- Compare multiple clustering algorithms
- Evaluate clustering performance

## Machine Learning Pipeline

- Data preprocessing
- Feature scaling using StandardScaler
- Principal Component Analysis (PCA)
- Elbow Method
- Silhouette Analysis
- Clustering model comparison

## Algorithms

- K-Means
- Gaussian Mixture Model (GMM)
- BIRCH
- Hierarchical Clustering

## Technologies

- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

## Results

The project compares several clustering algorithms using silhouette scores and visualizations to identify the most effective approach for grouping human activity data.
